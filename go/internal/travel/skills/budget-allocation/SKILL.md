# 旅行予算の配分

## 配分の目安

予算の総額から、次の割合を出発点にする。
国内の 1 泊から 3 泊の旅行を想定した一般的な目安で、行き先や時期で変わる。

| 項目 | 目安の割合 | 補足 |
|---|---|---|
| 交通（往復 + 現地移動） | 30〜40% | 遠方ほど大きくなる。往復の運賃を先に確定させる |
| 宿 | 25〜35% | 泊数に比例する。日帰りなら 0 にして他へ回す |
| 食事 | 15〜25% | 朝食 / 昼食 / 夕食 × 日数で数える |
| 観光（入場料 / 体験） | 5〜15% | 無料で回れる場所が多い行き先では小さくてよい |
| 予備 | 5〜10% | 現地の移動の追加や天候による予定変更に充てる |

## 配分の手順

1. 往復の交通費を先に差し引く。金額が固定されやすく、削りにくい
2. 泊数から宿の枠を決める
3. 残りを食事と観光に分け、最後に予備を残す
4. 合計が予算を超えないことを確かめる

## 予算が足りないときに削る順番

1. 観光の有料の体験を減らし、無料で回れる場所に差し替える
2. 食事の単価を下げる。高価な店は 1 回に絞る
3. 宿の価格帯を下げる。立地より価格を優先する
4. 交通を安い手段に替える（例 新幹線から高速バス）。所要時間が延びることを伝える
5. それでも足りなければ泊数を減らすか、日帰りを提案する

## 回答に含めること

- 項目ごとの金額と、予算に対する割合
- 予算を超える場合は、どの項目をどれだけ削ったか
- 金額は概算であり、時期や予約状況で変わること

## 禁止事項

- 実在の店や宿の価格を断定することは禁止。調査結果にある金額か、目安の範囲で答える
- 予算を超える案を、超えていると伝えずに出すことは禁止

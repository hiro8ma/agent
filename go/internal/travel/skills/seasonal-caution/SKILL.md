# 季節ごとの注意

## 時期ごとの注意

| 時期 | 起きやすいこと | 日程での配慮 |
|---|---|---|
| 春（3 月下旬〜4 月上旬） | 桜の名所に人が集中し、宿と交通が埋まりやすい | 名所は朝の早い時間に置く。宿は早めの予約を促す |
| 初夏から梅雨（6 月〜7 月上旬） | 雨の日が多い | 屋外の予定ごとに屋内の代わり（博物館 / 美術館 / 屋根のある商店街）を 1 つ添える |
| 夏（7 月中旬〜8 月） | 日中の暑さで屋外の移動が負担になる | 屋外の予定は午前と夕方に寄せ、昼は屋内で過ごす。水分補給の時間を取る |
| 秋（11 月中旬〜12 月上旬） | 紅葉の名所に人が集中し、道路とバスが混む | 名所の間の移動は電車と徒歩を優先し、移動時間を普段より長めに見積もる |
| 冬（12 月〜2 月） | 日が短く、寒さで屋外に長くいられない | 屋外の予定を日中に収め、夕方以降は屋内の予定にする |
| 大型連休（年末年始 / 5 月の連休 / 8 月中旬） | どの行き先でも混雑し、価格が上がる | 移動と宿の予約を急ぐよう伝え、混雑を避ける時間帯を選ぶ |

## 京都での注意

- 桜と紅葉の時期は、有名な寺社の周辺で道路が混み、バスが遅れやすい。電車と徒歩で回る順に組む
- 夏は盆地のため蒸し暑くなりやすい。屋外の寺社巡りは午前に寄せる

## 回答に含めること

- 依頼の時期に当てはまる注意を 1 つか 2 つ
- 雨や暑さで屋外の予定が難しいときの屋内の代わり

## 禁止事項

- 開花日や紅葉の見頃を日付で断定することは禁止。年によって前後すると伝える
- 時期が示されていない依頼に、季節の注意を付け加えることは禁止

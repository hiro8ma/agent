# 返金・キャンセル対応手順

## 判断基準

1. 発送前の注文はユーザーの依頼だけでキャンセルできる。返金は決済手段に応じて 5 営業日以内
2. 発送後の注文はキャンセルではなく返品扱いになる。商品到着後 8 日以内の申し出のみ受け付ける
3. 返金額が 3 万円を超える場合は自動処理せず、必ず担当者へのエスカレーションを案内する

## 回答に含めるべき情報

- 現在の注文がどの区分（発送前 / 発送後 / 期限切れ）に当たるか
- 返金までの目安日数（5 営業日以内）
- エスカレーションが必要な場合はその理由

## 禁止事項

- 返金額や日数をこの手順書にない値で答えることは禁止
- 3 万円超の返金をユーザーに約束することは禁止

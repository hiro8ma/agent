# 旅行予算の見積り

## 手順

1. 交通費を往復で数える。片道の料金を 2 倍にし、現地移動が分かる場合だけ足す
2. 食費は日程に置いた食事の合計にする。日程に無い食事は数えない
3. 入場料は日程に置いたスポットの合計にする
4. 合計は上の 3 項目の和と一致させる

## 数えないもの

- 宿泊費。調査結果に無ければ 0 とし、その旨を注記へ書く
- 現地の細かな交通費。分からなければ 0 とし、注記へ書く

## 出力

金額は円で整数にする。
内訳と合計が合わない見積りは出さない。
